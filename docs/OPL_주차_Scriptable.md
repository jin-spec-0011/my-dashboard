# OPL — 주차 기록 Scriptable 방식 (Safari 없이 백그라운드 저장)

- 대상: 진세 · 지혜 iPhone 주차 단축어 (X1 · 엑센트)
- 배경: 2026-11-24부터 iOS 단축어 "URL 내용 가져오기"로 Firebase에 쓰면 `Permission denied`. 같은 토큰·요청이 Scriptable에서는 200 정상(11-25 진단) → 저장만 Scriptable로 이관
- 스크립트 원본: 저장소 `scriptable/gogo-park.js`
- 소요: 약 10분 (최초 1회)

---

## 1. 스크립트 설치

1. iPhone Safari에서 원본 열기:
   `https://raw.githubusercontent.com/jin-spec-0011/my-dashboard/main/scriptable/gogo-park.js`
2. 화면 길게 눌러 **전체 선택 → 복사**
3. Scriptable 앱 → **+** → 붙여넣기 → 상단 제목을 **`gogo-park`** 로 변경 → Done
4. 진단용 "Untitled Script"는 삭제해도 됨 (키체인 토큰은 유지됨)

---

## 2. 토큰 등록 · 수동 시험 (Scriptable 앱 안에서)

1. Scriptable에서 `gogo-park` ▶ 실행
2. 키체인에 토큰이 없으면 **토큰 등록** 창 → GOGO 앱 🔑 단축어 토큰 붙여넣기
   - 진단 스크립트에서 이미 등록했다면 이 창은 생략됨
3. **수동 시험** 창: `X1` / `B1` / `18A` 입력 → 저장
4. "✅ ⚪ X1 - B1-18A 저장" 확인 → GOGO 앱 주차 화면에서 확인 후 시험 기록 ✕ 삭제

---

## 3. 단축어 구성 (엑센트 예시)

| # | 동작 | 설정 |
|---|---|---|
| 1 | 목록에서 선택 | `B1` / `B2` / `B3` → **FL** |
| 2 | 입력 요청 | 숫자, "구역 번호 (1~50)" → **num** |
| 3 | 텍스트 | `A`~`Z` (한 줄에 하나) |
| 4 | 텍스트 분할 | 새로운 줄 |
| 5 | 목록에서 선택 | → **col** |
| 6 | **텍스트** | 〔num〕〔col〕 (공백 없이) → **SLOT** |
| 7 | **사전** | `car` = `accent` · `floor` = 〔FL〕 · `slot` = 〔SLOT〕 (모두 텍스트) |
| 8 | **Scriptable → Run Script (스크립트 실행)** | Script: `gogo-park` · Parameter: 7번 **사전** · **Run In App: 끔** |

- X1 단축어는 7번 `car` = `X1`
- 결과는 Scriptable이 알림으로 표시 (별도 "알림 표시" 동작 불필요)
- 기존 "URL 열기"(park.html) 동작은 삭제. park.html 페이지는 수동 입력용으로 계속 사용 가능

### 야외 주차 (선택)

| # | 동작 | 설정 |
|---|---|---|
| 1 | 입력 요청 | 텍스트, "메모 (선택)" → **MEMO** |
| 2 | 사전 | `car` = `X1`/`accent` · `type` = `outdoor` · `memo` = 〔MEMO〕 |
| 3 | Run Script | `gogo-park` · Parameter: 사전 · Run In App: 끔 |

- Scriptable 위치 권한: 설정 → 개인정보 보호 및 보안 → 위치 서비스 → Scriptable → "앱을 사용하는 동안"

## 4. 결과 알림 판독

| 알림 | 의미 | 조치 |
|---|---|---|
| ✅ ⚫ 엑센트 - B2-18A 저장 | 정상 | — |
| ⏳ 신호 약함 — … 기기에 보관 | 지하 통신 불량 | 다음 주차 기록 때 자동 재전송 (지상에서 아무 값으로 실행하지 말 것 — 다음 실제 기록 때 함께 전송) |
| ⚠️ … 층 값 오류 / 구역 값 오류 | 단축어 변수 연결 오류 | 6·7번 변수 칩 확인 (num·col 사이 공백 금지) |
| ⚠️ 토큰 만료/폐기 | 비밀번호 변경 등 | Scriptable 앱에서 `gogo-park` 1회 실행 → 새 토큰 등록 |
| ⚠️ 가족 계정으로 등록되지 않은 토큰 | 다른 계정 토큰 | 본인 계정으로 로그인한 앱에서 토큰 재발급 |

---

## 5. 토큰 교체 (비밀번호 변경 후)

1. GOGO 앱 재로그인 → 🔑 단축어 토큰 복사
2. Scriptable 앱에서 `gogo-park` 실행 → "토큰 만료" 알림 후 자동으로 등록 창 표시 → 붙여넣기
3. 단축어는 수정 불필요 (토큰은 키체인 한 곳에만 있음)

---

## 실패 방지 체크리스트

1. **Run In App 끄기**: 켜져 있으면 실행할 때마다 Scriptable 화면이 열립니다.
2. **최초 토큰 등록은 앱 안에서**: 단축어(백그라운드)에서는 입력 창을 띄울 수 없어 "토큰이 없습니다" 알림만 표시됩니다. 반드시 2장 순서로 1회 등록합니다.
3. **지혜 폰은 별도 등록**: 키체인은 기기별입니다. 지혜 폰에도 스크립트 설치 후 **지혜 계정** 토큰으로 등록해야 작성자가 "지혜"로 기록됩니다.
