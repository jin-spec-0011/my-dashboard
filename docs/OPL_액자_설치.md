# OPL — GOGO 디지털 액자 설치 (iPhone XS · iPad mini)

- 액자 주소: `https://jin-spec-0011.github.io/my-dashboard/frame.html`
- 소요: 기기 1대당 약 15분
- 준비물: 액자 전용 계정(이메일·비밀번호), 진세 폰(GOGO 앱, 액자 키 생성 완료), 거치대, 충전기

> ⚠️ 액자 기기에는 개인 Apple ID·Google 계정으로 로그인하지 않습니다.

---

## 1. 기기 준비

1. 공장 초기화 → 최신 iOS/iPadOS 업데이트
2. 설정 → 디스플레이 및 밝기 → **자동 잠금: 안 함**
3. 설정 → 일반 → 소프트웨어 업데이트 → 자동 업데이트 **끔**
4. 설정 → 손쉬운 사용 → **사용법 유도 모드 켬** (암호 설정)
5. 저장 공간 10GB 이상 비워 두기
6. Wi-Fi 연결 (본가에 둘 기기는 본가 Wi-Fi도 미리 저장)

## 2. 액자 페이지 설치

1. Safari에서 액자 주소 열기
2. 공유 버튼 → **홈 화면에 추가** → 이름 `GOGO액자`
3. 홈 화면의 **GOGO액자** 아이콘으로 실행 (이후 항상 이 아이콘으로 실행)

## 3. 로그인 · 등록

1. 액자 화면에서 액자 전용 계정 이메일·비밀번호로 로그인
2. 기기 이름 확인(예: iPad mini) → **등록 요청**
3. 진세 폰 GOGO 앱 → 🖼️ 가족 액자 → 액자 기기 → 새 요청 **승인**
4. 액자 화면이 **키 등록**으로 바뀜

## 4. 키 등록 · QR 복구 카드

1. 진세 폰: 가족 액자 → 해당 기기 → **🪪 QR 카드** → 액자 계정 이메일·비밀번호 입력 → 카드 만들기
2. 액자 화면: **📷 QR 스캔** → 카메라 권한 허용 → 진세 폰의 카드 QR을 액자 **전면 카메라** 앞에
3. 사진 슬라이드가 시작되면 완료
4. 진세 폰의 카드 화면을 캡처 → 명함 크기 인쇄·라미네이팅 → 거치대 뒷면 부착 → **캡처 파일 삭제**

## 5. 기기 설정 (진세 폰 GOGO 앱)

| 항목 | 본가 | 집 |
|---|---|---|
| 장소 | 본가 | 집 |
| 야간 | 00:00~06:00 | 근무에 맞춰 조정 |
| 날짜·시각 | 켬 | 켬 |
| 끊김 알림 | 켬 | 끔 가능 |
| QR 복구 | 켬 | 끔 가능 |

## 6. 사용법 유도 모드 시작

1. 액자 화면에서 **홈 버튼(iPad) / 측면 버튼(iPhone) 3번 클릭**
2. 사용법 유도 모드 → 시작
3. 종료는 같은 버튼 3번 클릭 → 암호 입력

## 7. 복구 (전화로 안내)

| 화면 | 부모님께 안내 |
|---|---|
| 큰 글씨 끊김 문구 + [QR 카드 대기] | "화면의 **QR 카드 대기**를 누르고, 뒤에 붙은 카드를 화면 위쪽 카메라에 대 주세요" |
| 홈 화면 (액자가 꺼져 있음) | "**GOGO액자** 아이콘을 눌러 주세요" |
| 검은 화면 | "충전 케이블이 꽂혀 있는지, 멀티탭이 켜져 있는지 봐 주세요" |
| "오프라인" 표시 | 사진은 계속 나옴. 공유기 전원 확인 요청 |

## 실패 방지 체크리스트

1. **출고 전 복구 시험**: Safari 데이터 삭제(설정 → 앱 → Safari → 방문 기록 및 웹 사이트 데이터 지우기) 후 QR 카드만으로 복구되는지 기기마다 확인합니다.
2. **카드 보관**: QR 카드에는 액자 계정 비밀번호와 사진 키가 들어 있습니다. 카드 분실 시 Firebase 콘솔에서 해당 액자 계정 비밀번호를 바꾸고 GOGO 앱에서 기기 등록을 해제한 뒤 다시 등록합니다.
3. **72시간 시험**: 두 기기를 집에서 3일 연속 켜 두고 화면 꺼짐·발열·잔상(XS)·사진 반영 시간을 확인한 뒤 본가에 설치합니다.
