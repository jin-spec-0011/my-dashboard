# OPL — 주차 입력 전용 페이지 (단축어 토큰 방식 대체)

- 대상: 진세 · 지혜 iPhone 주차 단축어
- 이유: 단축어 REST + refresh token 방식은 변수·헤더·토큰 문제로 깨지기 쉬움 (2026-11-24 장애) → 앱과 같은 로그인 방식의 전용 페이지로 대체
- 주소: `https://jin-spec-0011.github.io/my-dashboard/park.html`
- 소요: 약 5분

---

## 1. 최초 1회 — Safari 로그인

1. iPhone **Safari**에서 `https://jin-spec-0011.github.io/my-dashboard/park.html` 열기
2. Google 계정(또는 이메일)으로 로그인 → 상단에 `👤 진세` / `👤 지혜` 표시 확인
3. 야외 주차를 쓸 경우: 설정 → 개인정보 보호 및 보안 → 위치 서비스 → **Safari 웹 사이트** → "앱을 사용하는 동안"

> 홈 화면 GOGO 앱과 Safari는 로그인 저장소가 따로라서 Safari에서 한 번 더 로그인해야 합니다.

---

## 2. 단축어 교체

| 단축어 | 동작 (1개) |
|---|---|
| X1 주차 | **URL 열기** `https://jin-spec-0011.github.io/my-dashboard/park.html?car=X1` |
| 엑센트 주차 | **URL 열기** `https://jin-spec-0011.github.io/my-dashboard/park.html?car=엑센트` |

- 기존 주차 단축어(토큰 텍스트 포함)는 새 단축어 확인 후 **삭제**
- 야외로 바로 열고 싶으면 주소 끝에 `&type=outdoor` 추가

---

## 3. 사용

| 위치 | 순서 |
|---|---|
| 지하 | 층(B1~B3) → 구역(최근 칩 탭 또는 번호·열 선택) → **📌 저장** |
| 야외 | 🌳 야외 → GPS 자동 수신(±m 확인) → 메모(선택, 20자) → **📌 저장** |

- 작성자는 로그인 계정으로 자동 (진세 / 지혜)
- 사진은 지원하지 않음 (사진이 필요하면 GOGO 앱 주차 화면 사용)
- 차량별 최신 2개만 유지 (앱과 동일)

---

## 4. 문제 해결

| 화면 표시 | 원인 | 조치 |
|---|---|---|
| ⏳ 전송 대기 n건 | 지하 신호 불량 | 그대로 두면 연결 시 자동 저장. 페이지를 닫아도 다음에 열 때 재전송 |
| ⛔ 저장 권한이 없습니다 | 가족 계정이 아닌 계정으로 로그인 | 로그아웃 → 가족 계정으로 재로그인 |
| ⚠️ GPS 좌표가 없습니다 | 위치 권한 거부 · 실내 | 1장 3번 권한 확인 → 🔄 위치 다시 받기 |
| 로그인 화면 반복 | Safari 쿠키 차단 | 설정 → Safari → "모든 쿠키 차단" 끄기 |

---

## 실패 방지 체크리스트

1. **최초 로그인은 Safari에서**: 단축어 "URL 열기"는 Safari로 열립니다. 진세·지혜 폰 각각 1회 로그인 후 사용합니다.
2. **대기 표시 확인**: 지하에서 저장 후 `⏳ 전송 대기`가 보이면 지상에서 페이지를 한 번 더 열어 `✅ 저장 완료`를 확인합니다.
3. **구 단축어 정리**: 토큰이 들어 있는 기존 주차 단축어는 삭제합니다. 운행 단축어(A·B)는 토큰 방식을 유지하므로 토큰 교체 시 그 4개만 바꿉니다.
