# OPL — 주행 기록 Scriptable 방식 (X1 · 엑센트 블루투스 자동 적산)

- 대상: 블루투스 자동화 4개 (X1 연결/해제, 엑센트 연결/해제)
- 배경: 2026-11-24부터 단축어 "URL 내용 가져오기" → Firebase `Permission denied`. Scriptable 경유는 정상 → 단축어 A·B 로직을 `scriptable/gogo-trip.js`로 이관
- 데이터 규격·앱·보안 규칙: 변경 없음 (`trip_pending`, `trip_logs`)
- 소요: 약 15분 (최초 1회)

---

## 1. 스크립트 설치

1. Safari: `https://raw.githubusercontent.com/jin-spec-0011/my-dashboard/main/scriptable/gogo-trip.js` → 전체 선택 → 복사
2. Scriptable → **+** → 붙여넣기 → 제목 **`trip`** → Done

## 2. 최초 등록 · 시험 (Scriptable 앱 안에서)

1. `trip` ▶ 실행 → 메뉴에서 **카카오 키 다시 등록** → 카카오 디벨로퍼스 **REST API 키**(32자리) 붙여넣기 → "✅ 카카오 키 등록 완료"
   - 토큰은 주차 스크립트에서 등록한 값을 공유 (따로 등록 불필요)
2. 위치 권한: 설정 → 개인정보 보호 및 보안 → 위치 서비스 → Scriptable → **앱을 사용하는 동안 + 정확한 위치**
3. 시험: `trip` 실행 → **엑센트 출발** → GOGO 앱 차량 관리에 "🟢 운행 중" 확인
4. 1분 이상 지나 **엑센트 도착** → "🏁 운행 기록 완료" 또는 "⏹"(1km·10분 미만 폐기 — 정상)
   - 제자리 시험은 거리 0이라 폐기되는 것이 정상. 실제 기록은 다음 운행으로 확인

## 3. 단축어 · 자동화 (4개)

각 자동화의 기존 단축어 내용(토큰 교환, 카카오 호출, 만약 등)을 **전부 삭제**하고 아래 2개 동작만 둡니다.

| 자동화 | 1. 사전 | 2. Run Script |
|---|---|---|
| X1 블루투스 **연결됨** | `car` = `X1`, `phase` = `start` | `trip` · Parameter = 사전 · Run In App 끔 · 실행 시 보기 끔 |
| X1 블루투스 **연결 해제됨** | `car` = `X1`, `phase` = `end` | 동일 |
| 엑센트 **연결됨** | `car` = `accent`, `phase` = `start` | 동일 |
| 엑센트 **연결 해제됨** | `car` = `accent`, `phase` = `end` | 동일 |

- 자동화 설정: **즉시 실행** · **실행 시 알림** 끔
- 블루투스 해제 시 주차 기록도 함께 쓰는 경우: 같은 단축어 안에서 `trip`(end) → `parking` 순서

## 4. 동작 · 알림

| 상황 | 처리 | 알림 |
|---|---|---|
| 정상 출발 / 도착 | 서버 저장 | 없음 (조용히 처리) |
| 출발 GPS 실패 (지하) | 직전 도착 좌표 사용 | 없음 |
| 출발 GPS 실패 + 직전 좌표 없음 | 이번 운행 기록 안 함 | ⚠️ |
| 도착 GPS 실패 | 기록 생략 (계기판 보정으로 흡수) | ⚠️ |
| 지하에서 통신 실패 | 기기 대기열 보관 → 다음 출발/도착 때 자동 저장 | 없음 |
| 1km 미만 & 10분 미만 | 블루투스 순간 끊김으로 폐기 | 없음 |
| 1km 미만 & 10분 이상 | `roundtrip_suspect` 저장 | ⚠️ 앱에서 실제 거리 입력 |
| 30분 이내 재연결 | 같은 운행으로 유지 | 없음 |
| 카카오 키 오류 / 토큰 만료 | 대기열 보관 | ⚠️ (Scriptable 앱에서 재등록) |
| 대기열 7일 경과 | 폐기 | 🗑 |

## 실패 방지 체크리스트

1. **스크립트 이름 = `trip`**: 단축어 Run Script가 이름으로 호출합니다. 이름을 바꾸면 4개 자동화가 모두 실패합니다.
2. **Parameter에 사전 연결**: Texts에 넣어도 동작하지만, 사전이 비어 있으면 "입력이 없어 종료" 출력만 남고 기록되지 않습니다. 설치 직후 실제 운행 1건이 "최근 운행"에 생기는지 확인합니다.
3. **카카오 키는 REST API 키**: JavaScript·네이티브 앱 키를 넣으면 등록 시 "카카오 키 오류 (HTTP 401)"가 표시됩니다. 카카오모빌리티 길찾기 사용 설정도 켜져 있어야 합니다.
